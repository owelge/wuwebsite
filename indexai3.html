[AI-PILOT // LOG_01: DIE URSPRÜNGE]

Tech meets Business

// PIONIERZEIT // SYSTEM: WELNET // ANNO 1999

1999. Das Web ist eine Einbahnstraße. Seiten werden gelesen, nicht benutzt. Es gibt keine Vorbilder, keine Playbooks, keine Frameworks. Nur die Ahnung, dass Menschen im Netz etwas anderes wollen: mitreden, Spuren hinterlassen, dazugehören.

Oliver Welge baut es. Allein. welnet.de wird einer der größten kostenlosen Gästebuch-Dienste Deutschlands – über 100.000 Mitglieder, lange bevor jemand „Social“ sagt. Nicht die Technik macht den Unterschied. Das Produkt trifft einen Wunsch, für den es noch kein Wort gibt.

Das Muster ist damit gesetzt. Es wird sich wiederholen.

[AI-PILOT // LOG_02: UNTERNEHMERTUM]

Vom Core-Dev zum Unternehmer

// SCALE PHASE // WELUSE GMBH // AGENTUR // 2008

Ein Produkt, das Menschen wollen, ist der Anfang. Ein Geschäftsmodell, das mitwächst, ist der Rest. 2008 gründet Oliver die weluse GmbH in Kiel. Aus der Softwareschmiede wird eine Digitalagentur, 20 Spezialisten, 15 Jahre.

In dieser Zeit entstehen die digitalen Plattformen von Otto, AboutYou, XXXLutz und MediaMarkt. Produkte, an denen Millionen Menschen jeden Tag entscheiden, ob sie bleiben. Sie alle gehören zu seinen Kunden.

Und wieder stimmt das Timing: Mit snapmobl setzt er auf Mobile-First, als der Desktop noch als gesetzt gilt. Ein weiteres skalierbares Geschäftsmodell – diesmal nicht nur in Deutschland, sondern auch in den USA.

[AI-PILOT // LOG_03: DIE TRANSFORMATION]

Flying Solo. Powered by AI.

// STATE OF THE ART // TECH ADVISORY // 2026

Zum dritten Mal verschiebt eine Technologie die Regeln. Zum dritten Mal ist Oliver früh dort. 2026 baut er weluse radikal um: kein Agentur-Apparat mehr, sondern Tech Advisory aus einer Hand. Sein Team besteht aus AI-Agenten. Die Richtung gibt er vor.

Das Werkzeug ist neu. Das Urteil nicht. Was ein Produkt für seine Nutzer richtig macht, welches Geschäftsmodell trägt, welche Technologie gerade reif ist – das hat er in drei Jahrzehnten dreimal bewiesen. Web. Mobile. Jetzt KI.

Neu ist nur eines: Er braucht dafür kein Team von zwanzig mehr. Was früher Quartale dauerte, entsteht heute in Wochen.
