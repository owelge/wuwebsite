[AI-PILOT // LOG_01: DIE URSPRÜNGE]

Tech meets Business

// INIT NODE: ATDT 0431_ // CONNECT 56K // ANNO 1999

1999. Das Modem fiept, die Verbindung steht. Das Web ist eine Einbahnstraße: Seiten werden gelesen, nicht benutzt. Es gibt keine Playbooks, keine Frameworks, keine Vorbilder. Nur die Ahnung, dass Menschen im Netz etwas anderes wollen – mitreden, Spuren hinterlassen, dazugehören.

Oliver Welge baut es. Allein. welnet.de wird einer der größten kostenlosen Gästebuch-Dienste Deutschlands, über 100.000 Mitglieder – in einer Zeit, in der das eine gewaltige Masse ist, lange bevor jemand „Social“ sagt. Nicht die Technik macht den Unterschied. Das Produkt trifft einen Wunsch, für den es noch kein Wort gibt.

Das Muster ist damit gesetzt. Es wird sich wiederholen.

[AI-PILOT // LOG_02: UNTERNEHMERTUM]

Vom Core-Dev zum Unternehmer

// NODE EXPANSION // WELUSE GMBH // SCALING BUSINESS MODELS // 2008

Ein Produkt, das Menschen wollen, ist der Anfang. Ein Geschäftsmodell, das mitwächst, ist der Rest. 2008 gründet Oliver die weluse GmbH in Kiel. Aus der Softwareschmiede wird eine Software- und Produktagentur, 20 Spezialisten, 15 Jahre.

In dieser Zeit entstehen die digitalen Plattformen von Otto, AboutYou, XXXLutz und MediaMarkt. Produkte, an denen Millionen Menschen jeden Tag entscheiden, ob sie bleiben. Diese und viele weitere Marktführer gehörten zu seinen Kunden.

Und wieder stimmt das Timing: Mit snapmobl setzt er auf Mobile-First, als der Desktop noch als gesetzt gilt. Ein weiteres skalierbares Geschäftsmodell – diesmal nicht nur in Deutschland, sondern auch in den USA. Weitere Projekte im Social Web werden zum Reallabor: dort lernt er, was Nutzer annehmen und was nicht.

[AI-PILOT // LOG_03: DIE TRANSFORMATION]

Flying Solo. Powered by AI.

// STATE OF THE ART // TECH ADVISORY // 2026

Zum dritten Mal verschiebt eine Technologie die Regeln. Zum dritten Mal ist Oliver früh dort. 2026 baut er weluse radikal um: kein Agentur-Apparat mehr, sondern Tech Advisory aus einer Hand. Sein Team besteht aus AI-Agenten. Die Richtung gibt er vor.

Das Werkzeug ist neu. Das Urteil nicht. Die Frage für Unternehmen ist heute selten, ob sie Technologie einsetzen – sondern welche, und wie sie damit Geld verdienen. Genau an dieser Schnittstelle von Technik und Business entstehen die teuren Fehlentscheidungen. Und genau dort hat Oliver drei Jahrzehnte verbracht: Web. Mobile. Jetzt KI.

Er hat das Web nicht nur kommen sehen. Er hat funktionierende Unternehmen darin gebaut. Neu ist nur eines: Er braucht dafür kein Team von zwanzig mehr. Was früher Quartale dauerte, entsteht heute in Wochen.
